
# What is it?

This is a note taking app which allows you to keep on track with your daily tasks.

It uses a calendar to help you schedule your daily objectives ensuring you complete them on time.

Tasks made simple, and owned by you.

# Front End (TB)

### General Ideas
- Tasks will have customizable objectives and deadlines
- Notification Reminders to complete objectives before certain dates
- Task heirarchy focus (which task in a day has more focus: top of lists, reminders etc.. )

### Features
- Reusable tasks
- Automatic tasks (Every day, week, month etc.. )
- Show checked off tasks toggle
- View hidden checked off tasks tab
- Filtered tasks
